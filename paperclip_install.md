## Install Paperclip
```bash
sudo apt update && sudo apt install -y unzip
curl -fsSL https://fnm.vercel.app/install | bash
source ~/.bashrc
npm --version
fnm install --lts
npm install -g pnpm
pnpm --version
```

```bash
git clone https://github.com/paperclipai/paperclip.git
cd paperclip
pnpm install
pnpm build
pnpm dev
```
